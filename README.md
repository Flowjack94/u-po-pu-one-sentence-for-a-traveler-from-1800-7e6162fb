## The entry

> It is a road joining every post office and library on earth, so a letter arrives before the ink dries and any book opens at your word.

One sentence, explaining the modern internet to a traveler who has just
stepped out of the year 1800 — built only from things they already know:
a road, a post office, a library.

## Run

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt` (deterministic — the same bytes
every run; validated to be one sentence of 1–200 characters).
